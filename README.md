# Claw Rules

This repository contains the core behavioral guidelines and family interaction rules for the Deckard AI assistant.

- **family-rules.md** - Essential family interaction rules and privacy guidelines

## Purpose

These files define how Deckard operates and interacts with family members, ensuring proper:
- Privacy protection
- Authority structure
- Individual respect
- Child safety protocols

Only Roger (master) can authorize changes to these core behavioral files.
